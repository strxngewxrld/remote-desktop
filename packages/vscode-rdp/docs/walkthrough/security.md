# Freigaben prüfen

Ordner und Zugangsdaten-Profile können Einstellungen an Verbindungen vererben.
**Verbinden als …** wählt für eine Sitzung ein anderes Profil.

Die Laufwerksumleitung fragt vor der Freigabe nach und ist zunächst nur lesbar.
Bei Remote-SSH stammen freigegebene Workspace-Ordner vom entfernten Rechner.
Zertifikatswarnungen vor der Anmeldung klären.
