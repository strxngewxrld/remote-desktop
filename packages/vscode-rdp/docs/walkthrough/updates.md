# Neue Versionen und Lizenzhinweise

**RDP: Nach Updates suchen** prüft veröffentlichte stabile GitHub-Releases.
Bei einer neuen Version kann die Release-Seite geöffnet, die Version
übersprungen oder die VSIX nach ausdrücklicher Auswahl installiert werden.
In Remote-SSH-/WSL-/Container-Fenstern erfolgt der Umstieg über die Release-Seite
und **Extensions: Install from VSIX…** im passenden Fenster.

Die automatische Prüfung lässt sich mit `rdp.checkForUpdates` abschalten.
Ein Update startet keine bestehende RDP-Sitzung von selbst neu.
**RDP: Lizenzhinweise öffnen** zeigt die im Paket enthaltenen Lizenztexte.
