# Den Desktop im Editor öffnen

In der Remote-Desktop-Seitenleiste eine Verbindung hinzufügen oder eine
`.rdp`-Datei importieren. Alternativ öffnet **RDP: Verbinden mit…** eine
einmalige Sitzung. Server als `host` oder `host:port` eingeben.

Beim ersten Verbinden den Zertifikatsfingerabdruck prüfen. Passwörter können
im sicheren Speicher von VS Code gespeichert werden.
